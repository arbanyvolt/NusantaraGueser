# NusantaraGuesser — Tebak Sejarah Indonesia

Game edukasi interaktif bertema sejarah Indonesia (*single-file HTML*), di mana pemain menebak **lokasi** dan **tahun** berbagai peristiwa bersejarah di Nusantara.

## Cara Bermain
1. Amati foto dan petunjuk peristiwa sejarah Indonesia.
2. Pilih tahun dan lokasi pada peta interaktif Nusantara.
3. Dapatkan skor berdasarkan akurasi jarak dan tahun!

Buka `index.html` atau `NusantaraGueser.html` langsung di browser, atau akses melalui **GitHub Pages** jika sudah diaktifkan.
